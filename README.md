# API Consulta IP

API REST desenvolvida em Python com FastAPI para extração automática de IPs LAN, WAN, SBC e SIPTG.

## Tecnologias

- Python
- FastAPI
- Swagger/OpenAPI
- JSON
- Uvicorn

## Funcionalidades

- Extração de IPs LAN
- Extração de IPs WAN
- Extração de IPs SBC
- Extração de IPs SIPTG
- Persistência em JSON
- API REST
- Swagger

## Executar

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```
